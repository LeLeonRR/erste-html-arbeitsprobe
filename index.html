Meine HTML-Arbeitsprobe

Diese Webseite habe ich als Arbeitsprobe für meine Bewerbung um eine Ausbildung zum Fachinformatiker für Anwendungsentwicklung erstellt. Sie zeigt meine ersten Grundlagen in HTML und mein Interesse an der Webentwicklung.

Warum ich Fachinformatiker werden möchte

Ich interessiere mich für Anwendungsentwicklung, weil ich spannend finde, wie aus einzelnen Befehlen Schritt für Schritt eine funktionierende Anwendung entsteht. Besonders motiviert mich, dass man mit Code eigene Ideen umsetzen und Probleme lösen kann.

Was ich bisher gelernt habe

  • Grundstruktur einer HTML-Seite
  • Überschriften und Absätze
  • Listen mit ul- und li-Tags
  • einfache Formatierungen mit Farben und Schriftgrößen
  • erste Nutzung von GitHub

Was ich als Nächstes lernen möchte

  • CSS für bessere Gestaltung
  • JavaScript für interaktive Webseiten
  • Git und GitHub sicherer verwenden
  • kleine eigene Projekte erstellen

Schlusssatz

Mein Ziel ist es, meine Grundlagen während der Ausbildung weiter auszubauen und praktisch anzuwenden. Ich bin motiviert, Neues zu lernen und mich Schritt für Schritt in der Anwendungsentwicklung zu verbessern.
